Get started on macOS

The menu-bar tray is the interface. Install, start it once, and everything else is a click.

1

Install the package

Double-click the downloaded .pkg — or run it from a terminal. It puts qcontrol on your PATH and sets up machine trust automatically. No extra setup.

sudo installer -pkg ~/Downloads/qcontrol-latest-macos-arm64.pkg -target /copy
Unsigned build: Gatekeeper flags it as from an unidentified developer. The terminal command above installs it anyway. If you double-click it in Finder and it's blocked, open System Settings → Privacy & Security and click Open Anyway.

Rolling out to a fleet? Push the same .pkg through MDM — the installer needs no logged-in user and sets machine trust in its postinstall.

2

Start qcontrol

Run this once. qcontrol begins monitoring in the background and its icon appears in your menu bar — that's your whole interface from here on.

qcontrol startcopy

Stop it anytime with qcontrol stop. For fleet rollout, run qcontrol start from a per-user LaunchAgent — the tray needs a logged-in desktop session to appear.
