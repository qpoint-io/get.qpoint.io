Get started on macOS

The menu-bar tray is the interface. Install, open it once, and everything else is a click.

1

Install the package

Double-click the downloaded .pkg — or run it from a terminal. It puts qcontrol on your PATH and sets up machine trust automatically. No extra setup.

sudo installer -pkg ~/Downloads/qcontrol-latest-macos-arm64.pkg -target /copy
Unsigned build: Gatekeeper flags it as from an unidentified developer. Install with the command above, or in Finder right-click the .pkg → Open.

Rolling out to a fleet? Push the same .pkg through MDM — the installer needs no logged-in user and sets machine trust in its postinstall.

2

Open qcontrol

Run this once to launch the tray. A qcontrol icon appears in your menu bar — that's your whole interface from here on.

qcontrol scancopy

To keep it monitoring in the background, or run it headless on a managed fleet, use qcontrol start (stop with qcontrol stop) — or run it via MDM as a launch agent.
